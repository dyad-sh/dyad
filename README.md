# Cat

Cat is a local, open-source AI app builder. It is fast, private, and designed to keep your development workflow under your control — like Lovable, v0, or Bolt, but running on your machine.

## Features

- **Local-first**: Build locally with less infrastructure and no mandatory hosted workspace.
- **Bring your own keys**: Use supported AI providers with your own credentials.
- **Cross-platform**: Built with Electron for desktop workflows.
- **Modern Cat UI**: A clean green-and-neutral design system using Plus Jakarta Sans, Source Serif 4, and JetBrains Mono.

## Development

```bash
pnpm install
pnpm dev
```

## Packaging

```bash
pnpm make
```
